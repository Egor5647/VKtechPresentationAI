# Локальная проверка моделей

Дата проверки: 16 сентября 2026 года.

## Конфигурация

- MacBook Pro, Apple M4 Pro, 12 CPU cores, 16 GPU cores;
- 24 GB unified memory;
- `mlx-vlm==0.7.1`, Metal, 8-bit KV-cache, одна активная sequence;
- максимальная сторона передаваемого изображения: 896 px;
- строгий structured output через JSON Schema.

завершили аудит. Замеры выполнены при прогретых моделях и не являются p50/p95.

## Найденное при интеграции Ministral

Первая версия общей схемы не фиксировала длину массива `slides`: Ministral вернул
валидный JSON, но другое число слайдов. Gateway теперь добавляет к схеме конкретного
запроса `minItems=maxItems=slide_count`; повторный прогон вернул ровно 12 слайдов.
Промпт также явно запрещает служебную цифровую нумерацию заголовков, чтобы она не
смешивалась с числами из источников.

## Прогон на предоставленной презентации

Вход: 45-слайдовая учебная презентация по массивам и файловому вводу-выводу в
C++. Импорт сгруппировал раскрывающиеся слайды в 48 смысловых блоков, выделил 12
обязательных фактов, сохранил 10 наборов заметок докладчика и извлёк 44 уникальных
изображения. Для обеих моделей использован один и тот же contact sheet из четырёх
исходных изображений.

| Метрика | `fast`: Qwen3-VL-4B | `quality`: Ministral 3 14B |
| --- | ---: | ---: |
| Планирование | 25,633 с | 72,536 с |
| Vision-аудит A/B/C | 32,211 / 32,641 / 29,731 с | 28,949 / 29,110 / 33,128 с |
| Полный pipeline | 132,167 с | 179,247 с |
| Нарушения A/B/C | 18 / 19 / 19 | 3 / 1 / 4 |
| Использование исходных иллюстраций | нет | да |
| Deadline 300 секунд | выполнен | выполнен |

У Ministral все нарушения относятся к детерминированному правилу D18 о низком
заполнении слайда. Qwen дополнительно сформировал ложные контекстуальные выводы,
например трактовал обычный заголовок как опечатку или служебный мусор. На этом
материале Ministral лучше подходит для основного режима, несмотря на более долгое
планирование. Qwen остаётся быстрым черновым режимом. Это один источник без
эталонной разметки, поэтому precision/recall по C01–C11 пока не вычисляются.

## Ограничения

- Отдельных корпоративных файлов шрифтов нет; зависимые проверки остаются
  `unknown`.
- T2I endpoint для Z-Image-Turbo не настроен.
- Проверена одна фактическая учебная презентация; для статистики нужен набор из
  нескольких источников с ручной разметкой ожидаемых ошибок.
- Нужны повторные замеры холодного запуска, p50/p95 и проверка memory pressure при
  одновременной работе LibreOffice, API и браузера.
