# Модели и API

## Основной контур Polza.ai

Сервис использует единый API-ключ Polza.ai и два официальных endpoint:

- `POST https://polza.ai/api/v1/chat/completions` — планирование, переписывание и vision-аудит;
- `POST https://polza.ai/api/v2/images/generations` — генерация иллюстраций;
- `GET https://polza.ai/api/v1/media/{id}` — ожидание асинхронной генерации;
- `GET https://polza.ai/api/v1/models` — проверка доступности моделей.

| Режим | ID модели | Роль |
| --- | --- | --- |
| `quality` | `qwen/qwen3.8-27b` | основной мультимодальный планировщик и аудитор |
| `fast` | `qwen/qwen3-vl-8b-instruct` | быстрый мультимодальный режим |
| изображения | `qwen/image-2` | иллюстрации для семантически подходящих слайдов |

Режим выбирается через `MODEL_MODE=quality|fast`. Идентификаторы закреплены в
`config/models.yaml` и могут быть переопределены только разрешёнными значениями.

## Надёжность и контроль ответа

Gateway передаёт Pydantic JSON Schema через `response_format=json_schema`. Если
выбранный маршрут отклоняет строгую схему, запрос повторяется с
`response_format=json_object`, после чего результат всё равно проходит полную
Pydantic-валидацию. Невалидный ответ получает одну корректирующую попытку.

Ответы 429 и временные 5xx повторяются с экспоненциальной задержкой. Ошибки 401,
402 и 403 преобразуются в понятные сообщения без тела ответа и без API-ключа.
Изображения поддерживают немедленный base64/URL ответ и асинхронный task ID.
Полученный файл проверяется Pillow до сохранения.

Ключ хранится только в `.env`, который исключён из Git. Манифест задания содержит
имя провайдера, модель, длительность и статус запроса, но не заголовки и секреты.

## Проверка

```bash
make check-api
./scripts/check_polza.py --chat
```

Первая команда читает каталог и проверяет, что три настроенных model ID доступны
этому ключу. Вторая дополнительно выполняет один короткий платный текстовый запрос.

## Локальная совместимость

Старые MLX-VLM и Z-Image адаптеры оставлены для воспроизводимости предыдущих
замеров. Они запускаются только явно: `make run-local`. Основной `make run` не
проверяет локальные веса, не запускает model server и не занимает память GPU.
