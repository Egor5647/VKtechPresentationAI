# Модели

## Qwen3.8-27B

- Репозиторий: `Qwen/Qwen3.8-27B`
- Фиксированная revision: `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`
- 27 781 427 952 параметра, открытые веса, Apache 2.0
- Роли: планирование содержания и контекстуальный vision-аудит
- Карточка: https://huggingface.co/Qwen/Qwen3.8-27B

В режиме отбора модель запускается на собственном GPU или через совместимый внешний
endpoint. В финале `MODEL_PROFILE=final` требует `VK_BASE_URL`; манифест помечает
провайдера `vk`, и тихий переход на другой endpoint запрещён.

Полный BF16 checkpoint занимает около 55,6 GB без KV cache и служебной памяти.
Начальная рекомендация — GPU с 80 GB VRAM. На меньшем GPU нужен подтверждённый
квантизованный профиль; качество схем и vision нужно измерить заново.

Числовые графики, таблицы и схемы T2I не рисует. Изображение имеет prompt, model
revision и происхождение `generated`; оно не подтверждает факты.

## Контроль допуска

`config/models.yaml` проходит проверку перед первым вызовом. Для LLM/VLM лимит
35B, для T2I применяется более строгий лимит 20B. Допустимы только Apache 2.0 и
MIT. Каждый ответ проходит Pydantic-схему; после одной корректирующей попытки
задание завершается ошибкой. Тестовые doubles находятся только в `tests/` и не
подключаются из API или конфигурации production.

Окончательный выбор требует benchmark: соблюдение схем, полнота обязательных фактов,
качество русского текста, vision-проверки, latency, память и работа на неизвестном
шаблоне. Версия модели не обновляется автоматически.
