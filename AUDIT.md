# Аудит

Каждое замечание содержит стабильный ID, правило, категорию, статус, severity,
slide ID, element IDs, сообщение и evidence. Статусы: `pass`, `fail`,
`not_applicable`, `unknown`. Отсутствие шрифта, рендера или ответа модели всегда
даёт `unknown`.

## Детерминированные правила

| Коды | Область |
|---|---|
| D01–D07 | границы, пересечения, text fit, clipping, направляющие, поля и aspect ratio |
| D08–D13 | шрифты, шкала кеглей, палитра, происхождение layout, protected objects, контраст 4.5:1 |
| D14–D18 | число пунктов, длина пункта, таблицы, серии графика и заполнение |
| D19–D24 | открытие, заглушки, пустые слайды, нативность, подписи графика и дубли |

Дополнительно `FACT_COMPLETENESS` сверяет обязательные claim IDs с каждым вариантом.
Проверка чисел выполняется до Scene IR: плану запрещено вводить число, отсутствующее
в Content IR. График и embedded workbook создаются из одного Dataset.

Некоторые пороги являются предупреждениями. Обложка и разделитель исключаются из
плотности; pie chart не требует осей; исходный шрифт шаблона не считается нарушением;
фоновые элементы могут выходить за canvas; контейнер и его содержимое не считаются
конфликтом. Исключение должно оставаться в evidence, а не скрывать проверку.

## Контекстуальные правила

C01–C11 проверяют вывод в заголовке, соответствие содержимого, единую мысль,
происхождение фактов, наличие содержания, уместность изображений, служебный мусор,
опечатки, язык, уместность строк/легенд и связность соседних слайдов. Модель получает
рендеры, Scene IR и Content IR. Она может возвращать только известные rule, slide и
element IDs. Все пропущенные пары помечаются `unknown`.

## Исправления

Автоматически разрешены только ограниченные операции: вернуть объект в canvas,
уменьшить текст до следующего кегля из шкалы шаблона и удалить заглушку, которая
не происходит из source claim. Смысловые замечания, контраст, замена фактов и смена
композиции требуют явного редактирования. API принимает выбранные issue IDs и
ожидаемую версию; устаревший отчёт отклоняется. После patch выполняется полный
экспорт и повторный аудит.
